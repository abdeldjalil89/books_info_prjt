# Books to Scrape - Python Web Scraper

A robust and clean web scraping tool built with Python to extract book data (titles, prices, availability) from online listings and export it into a structured CSV format.

## Project Structure
- src/: Contains the core scraper script (scraper.py).
- data/: Stores the exported CSV data files (books_info.csv).
- requirements.txt: List of required Python dependencies.

## Built With
- Python 3
- Requests
- BeautifulSoup4
- lxml
